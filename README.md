# Delphi to Java Converter

## About the Project

The Delphi to Java Converter is a beginner-friendly Java project that converts selected Delphi statements into their equivalent Java statements.

The project demonstrates Core Java concepts, string handling, conditional statements, regular expressions, and input validation.

## Features

- Converts string variable assignments.
- Converts integer and decimal assignments.
- Converts Delphi `Writeln()` statements into Java `System.out.println()`.
- Converts Delphi `ShowMessage()` statements into Java `System.out.println()`.
- Handles empty input and invalid statements.
- Validates variable names and supported values.

## Technologies Used

## Example

**Delphi input:**

```pascal
name := 'Priya';
```

**Java output:**

```java
String name = "Priya";
```

## How to Run

1. Clone or download this repository.
2. Open Eclipse IDE.
3. Import the project into Eclipse.
4. Run `Main.java`.
5. Enter a Delphi statement and view the converted Java output.
